# F1 22 AI Race Engineer: handoff

## Goal and boundaries

Build a separate, read-only Windows pit-wall companion using F1 22's 2022 UDP output. The player drives. Do not modify the game, inspect its process memory, inject input, bypass protection, or run the game as administrator for the companion. Preserve low game overhead and honest uncertainty. The [README](README.md) describes the published project scope. The original workspace's master brief is not part of this repository.

## Implementation map

- `app/telemetry/`: loopback UDP receiver, strict header/length checks, player and shared rival motion/lap/history decoding, freshness-aware state, opt-in bounded capture/replay.
- `app/engineer.py`: alert priority/cooldowns and comparable lap-start fuel/wear diagnostics.
- `app/strategy.py`: conditional stay-out, one-stop and optional two-stop comparisons with explicit measured assumptions and uncertainty; no call when required data is absent.
- `app/intelligence.py` and `app/rivals.py`: serializable fresh race facts, low confidence estimates, deterministic question answers, limited adjacent-rival position/pace analysis.
- `app/conversation.py`: optional LLM intent classification only, with deterministic offline fallback.
- `app/history.py`: local SQLite structured laps/events/advice, debrief statistics, CSV/JSON exports.
- `app/dashboard.py`, `app/dashboard.html` and `app/track_map.py`: optional FastAPI/WebSocket loopback dashboard with typed questions, observed track outline, fresh car markers and selectable full-grid lap logs.
- `app/voice.py`: optional Vosk F8 push-to-talk and pyttsx3 speech in worker threads.
- `app/__main__.py`: CLI; `scripts/start.ps1`, `scripts/build.ps1` for Windows startup/package build.

See `README.md` for setup, flags and gameplay validation. Baseline runtime needs no third-party packages. Dashboard, voice and packaging extras are optional.
