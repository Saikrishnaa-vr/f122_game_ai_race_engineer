This recording is a development/regression fixture. It proves the recorded packet stream and code path; it does not prove that displayed values match the game's HUD, that a browser rendered smoothly, or that a VSC/safety-car response was accurate in live play. The race capture has no practice-preset comparison run. Keep the raw capture local; do not edit it.

The browser check verifies that the replayed data reaches the page; it does not measure game FPS or compare gaps with the game's HUD.

The grid now retains the last valid participant roster for the current session while raw Participants packet freshness remains explicit.
