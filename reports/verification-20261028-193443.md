## Fixes from this run

- Lap-start fuel/wear samples are now taken as relevant packets arrive, so the five-second report timer cannot miss a brief start-line window. Replay reports containing fuel estimates rose from 38 to 117.
- A two-metre tolerance handles float lap distance exceeding integer track length by less than one metre near the line. It prevents the lap 10 estimate from clearing before lap 11.
- Regression tests cover both estimator cases and noisy history events. The full suite passes: 86 tests.

## Limits

The capture establishes the behavior of the received UDP stream and local application. It does not compare decoded values with the game HUD or authenticate the UDP sender. The run supplied no measured pit-loss/pace assumptions, so the conditional pit-strategy model correctly withheld a recommendation. The game-provided pit window was ideal lap 5/latest lap 9 before the stop and zero after it; the original report inspected only the final Session packet. Dashboard, voice, microphone/headphones, FPS/frame pacing, flashback, safety-car, and packaged executable behavior were not exercised in this run.
